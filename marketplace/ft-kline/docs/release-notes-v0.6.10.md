# v0.6.10 · DSH 原生侧栏自动开图修复

- 修复新版 DSH 分析成功但没有自动打开 K 线标签：支持独立工具结果消息，继续校验调用身份与所属对话。
- 修复新标签打开后停在大盘页：将本次分析交接给同一对话的新标签，直接显示所请求标的。
- 通过新版宿主的实时事件与历史加载标记判断是否开图，避免快速结果丢失，加载旧消息不抢占页面。
- 保留经典侧栏、旧版工具结果格式及可选 Better Sidebar 适配；原生侧栏无需安装 Better Sidebar。
- UI 显示方式统一命名为“工作台标签”，不再用可选插件名指代宿主自带的标签入口。

已在 DSH 0.2.1-rc.5 的隔离 profile 中验证：旧包可复现、新包从收起状态自动打开上证指数、展开时切换沪深300、折叠后恢复主图；可见画布无零尺寸，控制台无错误。该宿主仍是预发布版本，不将其称为稳定版。

本次不更改价格形态、九转的识别或绘制规则。完整证据和验证范围见[验收记录](release-acceptance-v0.6.10.md)。npm 包名为 `@ftshare-lab/dsh-kline`；npm 下载量包含重复安装与更新，不代表独立安装人数。
