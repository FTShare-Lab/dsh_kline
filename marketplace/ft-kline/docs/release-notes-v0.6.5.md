# v0.6.5 · 宿主面板挂载接口与联动修复

- DSH 图表新增可选宿主面板挂载接口，支持有界布局、精简界面、外部标的联动及固定主题；内嵌视图提供就绪、打开标的、读取当前标的和设置主题的桥接口。面向宿主开发者，需要宿主接入挂载入口，并非安装后自动新增画布或模拟盘面板。接入方式见 [嵌入说明](https://github.com/FTShare-Lab/dsh_kline/blob/v0.6.5/docs/embedding.md)。相关贡献见 [PR #15](https://github.com/FTShare-Lab/dsh_kline/pull/15)。
- 修复宿主切换标的时将不同证券视为同一标的问题：保留交易所身份，仅归一化别名，按完整代码比较。上证指数 `000001.XSHG` 与平安银行 `000001.XSHE`、美股 `V.US` 与 `VZ.US` 均会正常切换；同一证券的别名回传不会重复打开图表。
- 修复移除固定 `theme` 属性后图表仍保留原主题的问题；解除固定配色会恢复宿主主题路径，无需重新挂载。
- 增加真实组件属性更新路径、跨市场代码、美股前缀及主题解除固定的回归测试；重新构建 DSH 客户端，并同步 Codex 安装包与公开 GitHub 插件源至 v0.6.5。

本次新增的面板接入接口属于 DSH 客户端。Codex 桌面图表和 CLI 模式沿用现有能力；本版未新增行情源、指标或绘图类型。

安装包：`dsh-kline-v0.6.5.tgz`、`ft-kline-v0.6.5.zip`，以及各自的 SHA-256 文件。GitHub 源用户刷新 `ftshare` 后重新安装插件并重开 Codex；固定版本用户下载新版安装包。

验证范围和限制见 [验收记录](release-acceptance-v0.6.5.md)。
