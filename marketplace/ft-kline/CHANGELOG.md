## 0.6.0 - 2026-11-03

### Added

- 新增独立插件 ID `ft-kline`。ChatGPT Desktop 的 Codex 通过 `ui://ft-kline/chart-v3` 提供完整图表、手动工作台及与自然语言共享的受控绘图链路。
- 同一图表对话中的自然语言换标的可携带不透明 `context_ref`，安全复用 App 当次内存凭据与自选状态；凭据不进入模型输出或磁盘。
- 无 Key 的沪深 A 股日/周/月等历史 K 线在 BaoStock 无响应时，会回退腾讯公开 JSON 日 K；两种来源均在图表中明确标注，分钟 K、ETF 与未限定代码不走该回退。
- 图表 App 同时消费 MCP `ui/*` 结果和 ChatGPT 的兼容结果入口；若首个图表结果未交付，会显示明确错误而非无限空白等待。
- Codex 当前图使用仅当前 stdio 连接与 App 实例有效的内存会话；30 分钟空闲、资源关闭或连接结束即销毁。状态明确区分服务端提交、UI 渲染回执和像素验证。
- Codex 复用 `get_chart_context → prepare_chart_edit → apply_chart_edit → get_chart_edit_status` 名称与版本/对象 ID/候选确认/一次性请求校验；旧快照式绘图接口不在 Codex 注册。
- 新增 `ft_kline_app_action` 的 App-only 白名单入口，覆盖行情加载、工作台计算/保存/删除、状态回执与本次会话 FTShare Key 配置；模型不可调用该入口。
- 新增 `pack:codex`，产物为 `ft-kline-v0.6.0.zip`；DSH 继续从原路径打包为 `dsh-kline-v0.6.0.tgz`，并各自产生 SHA-256。

### Compatibility and security

- DSH 现有工具、侧栏、图表服务和凭据优先级保持不变。Codex 服务不导入或启动 DSH 图表服务，也不读取 DSH 会话或凭据文件。
- Codex Desktop 优先使用环境变量中的 FTShare Key；App 输入的 Key 只驻留本进程内存且绝不回显或落盘。没有 Key 时保留匿名和免费指数能力，并显示限制。
- Codex CLI 使用独立入口，只提供行情、分析、TA-Lib 与结构化结果；它明确不支持交互图表，也不注册图表资源、当前图上下文或绘图写操作。

### Release status

- 本版仅供私有 marketplace 灰度，未提交公共插件目录。发布流程为 `v0.6.0-rc.N` 双包验证和哈希 → Draft Release → 人工核对 → 最终 `v0.6.0` 发布。
- 数据和图形不跨 Codex 对话持久化。私有灰度的人工 macOS/Windows 桌面验收清单见 [v0.6.0 验收说明](docs/release-acceptance-v0.6.0.md)。

## 0.5.0 - 2026-10-27

### Added

- 专业绘图工作台：手动点选并预览 SMA、EMA、BOLL、水平线、趋势线、平行通道、平台框、斐波那契与 ABC 标注；确认后与宿主对话共享稳定对象 ID 和受保护的修改 / 删除流程。
- 图表函数目录与结果引用：斐波那契、通道、范围框、带标签折线、条件序列线、价带、柱线、条件标注；拐点、回归通道、通道及平台候选保持只读，需明确确认候选才可落图。
- TA-Lib 0.8.2 的 201 个函数可搜索、分页并对当前已加载 K 线只读调用；SMA、EMA 与受限 BBANDS 结果可经明确请求转换为独立主图对象。新图表指标与分析摘要统一使用 TA-Lib 口径。

### Fixed

- 序列图形的来源指纹、跨周期与 30D 视口保持、压缩回执、逐根柱线绘制及右缘文字显示；旧引用和不明应用结果继续安全拒绝，不重复落图。
- 本地网页版直接开图可建立经核对的当前图来源；工作台参数错误给出明确反馈，确认或删除后清除未保存的虚线草稿。

### Limits

- ABC 是用户指定锚点的标注，不自动识浪；通道和平台候选不代表专业识别已验收。缠论、公式解释器、鼠标拖拽、撤销及完整服务重启后旧图续改未纳入本版。
- 当前为本地候选。发布前仍需同一归档的安装烟测、跨平台 CI 与自然语言入口最终复核，见 [验收说明](docs/release-acceptance-v0.5.0.md)。
