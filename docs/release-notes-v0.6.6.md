# v0.6.6 · 免 Key 跨市场搜索与错误提示修复

- 港美股证券目录的后台刷新不再依赖 FTShare SDK 或 Key：港股使用港交所公开列表，美股使用 Nasdaq 的两份交易所目录。输入搜索仍走本地缓存，不会逐次请求行情接口；网络失败保留缓存和内置常用目录。
- 常用美股内置条目由 4 个增加到 24 个，港股由 12 个增加到 20 个，并补充特斯拉、Meta、奈飞、港交所等中文别名。后台英文目录合并时保留别名；修复仅含 A 股的旧缓存阻止港美股更新的问题。
- 港股、美股历史行情接口失败后不再误用 A 股接口，保留原始权限、限流与上游故障分类。匿名访问受限不再声称“Key 有效”；HTTP 400 会提示检查市场、代码和参数。
- 修复 `BRK.B.US` 取数时被截为 `BRK` 的问题，保留完整股类代码。
- 无 Key 的市场页面明确说明板块排行尚未接入免费源，并区分匿名模式、权限不足与临时故障。DSH、Codex 双安装包和公开 GitHub 插件源同步至 v0.6.6。

**搜索目录与行情权限相互独立。本版没有新增港美股免费日 K 自动备用源，也没有开通免费的板块、新闻或分钟数据。** 部分美股日 K 在匿名访问下可用，港股等接口仍按数据源的实际权限返回结果；搜到标的不等于所有行情接口均可用。

GitHub 源用户刷新 `ftshare`，重新安装插件并重开 Codex。固定版本用户下载 `ft-kline-v0.6.6.zip`；DSH 使用 `dsh-kline-v0.6.6.tgz`。两包均附 SHA-256 校验文件。

能力边界及免费源评估见 [无 Key 说明](anonymous-market-support.md)，验证范围见 [验收记录](release-acceptance-v0.6.6.md)。
