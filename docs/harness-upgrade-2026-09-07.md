# Harness 0.1.2-rc.1 适配记录

日期：2026-09-07。状态：代码、自动化与最终在线验收完成（含独立搜索新入口）。

## 版本边界

- 从项目固定的 `@deepseek-ai/dsh 0.1.0-rc.6` 升级至 npm `latest/next` 当日指向的 `0.1.2-rc.1`。
- GitHub 更新的 `dsh-v0.1.3-alpha.1` 尚未发布到 npm，官方说明包含 Session 持久化破坏性变更及历史加载性能回退；本次未安装该 Alpha，不应称已适配 GitHub 最新实验版。
- dsh_kline 自身仍为本地修复的 0.1.5，未提交、推送或发布。

## 本次适配

1. 客户端声明改为依赖新版 `dsh-api-session-controller`，不再声明已拆分的 `dsh-client-runtime`。
2. 新版 `SessionSnapshot` 不再含渲染节点。图表改从当前会话 `binding.eventSource` 的公开事件窗口获取；以调用 ID 配对结果，按调用开始时间选择，保留旧节点读取分支。
3. 同时支持普通 `tool/call` / `tool/result` 与 PTC 嵌套 `tool/code-dispatch-start` / `tool/code-dispatch`。错误、其他工具、用户文本和无法配对的结果不能抢图。
4. 重新解析依赖锁，消除直接升级留下的旧版底层 peer 混装；项目 `pnpm peers check` 无问题。
5. 本机已安装的文件侧栏 `dsh-better-sidebar 0.12.3` 在新版启动时因 `settingsNamespace` 导出变更失败，已升级至声明兼容 Harness 0.1.2-rc.1 的 0.18.0。此项属于本机 web profile，不由本仓库锁文件管理。

## 最终在线验收

上一轮因并发修改与重启竞争暂停；用户确认另一任务完成后，保留其独立搜索入口改动，重新构建并串行重启 DSH/MCP 完成下列验收。

- 未调用 AI 的新对话可直接进入工作台；当前实现默认加载上证指数，并非完全空白。搜索工商银行得到 A 股和港股候选，点击 A 股直接加载并在刷新后恢复。
- 实际测试对话 A：`确认贵州茅台日线分析请求`。先独立搜索工商银行，再由普通模式 MCP 分析茅台 60 根日线；随后手动切换平安银行、周线和 RSI，刷新、切换对话及重启 DSH 后仍保持。
- 实际测试对话 B：`查询贵州茅台年线数据`。首次独立搜索五粮液并验证刷新恢复；后通过 PTC 嵌套 analyze_kline 生成茅台年线，实际 10 根、2017 起。关闭侧栏后发起新分析，结果成功时自动展开。
- A 的平安银行周线 / RSI 开启，与 B 的茅台年线 / RSI 关闭独立保留；原紫金矿业年线对话也未被覆盖。
- 重启后旧图快照可读，设置页“测试当前连接”仍能调用活跃 MCP 服务，提示日 K 已验证可用、分钟 K 需要有效 Key 及权限。
- 自选添加操作可用，测试使用独立浏览器配置，不修改用户原浏览器自选。
- 最终网页实际画布可见；最终回归未捕获页面未处理异常或请求失败。

本轮补修两个问题：旧工作台退出后的异步错误提示不再访问已销毁 DOM，退出后也不再注册新定时器；在当前对话新完成的分析会自动展开侧栏，历史结果恢复不强行展开。

## 已知边界与下一轮建议

- PTC 首轮模型误传 `period="1Y"`，工具按缺省日线执行；明确改为 `interval="year"` 后成功。属于模型参数使用与未知字段校验的改进项，不应描述为年线算法回归。下一轮建议对未知参数拒绝并给出可修正提示，避免静默采用默认值。
- 独立搜索、AI 分析均按当前会话保留图表状态；自选列表和数据源配置仍是共享偏好。
- 常用证券目录仍非全市场；匿名行情权限与历史深度仍由上游决定。

新版网页使用启动时生成的认证链接；重启后应重新打开该入口，不关闭认证，也不把 token 写进报告或仓库。
