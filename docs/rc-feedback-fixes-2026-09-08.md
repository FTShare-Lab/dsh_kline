# RC 用户反馈修复验收（v0.2.0-rc.2）

基于 `v0.2.0-rc.2` 的发布候选完成的本地验收记录。

## 修复范围

- 右上角入口改为纯文字 `UI`，移除图标和提示圆点，窄栏仍显示文字。
- 品牌保留“非凸K线助手 / dsh_kline”。旧默认 Tab 标题在所属当前对话挂载后迁移；不修改其他插件、其他对话或用户自定义标题。
- 修复 `chart_session_unavailable`：原全局服务定位文件被已退出的临时测试 MCP 覆盖。改为 `.runtime/services/<Harness PID>.json`，通过启动环境显式传递宿主 PID；旧的直接 stdio 启动方式使用父 PID。宿主只访问自己的记录，失效时不借用其他实例。原有 token 快照及对话解析逻辑保留。
- 通过 Bash 调用 bootstrap，不再依赖发布包中的可执行位。
- 对缺失、旧版、异常及循环布局做防御，隔离服务读取/关闭/卸载错误；显式返回 Tab 注册清理函数。
- README 更新 UI 名称、补充搜索工具，明确自动打开偏好仅控制 Tab 模式。
- Tab 模式首次进入每个对话添加一次入口，通过公共 API 恢复先前活动标签，不展开工作台；使用本插件自己的对话级收据记住手动关闭。分析后的自动打开偏好仍独立生效。
- NVDA 失败根因：FTShare 美股日 OHLC 不传日期实际只返回最新一根；传单侧 `end_date` 才返回完整历史（避免双侧日期的三天窗口限制）。修复日期请求，并将日期字段按纽约交易日收盘时间归一化，避免跨日和跨月偏移。
- 美股分钟接口明确拒绝美股后缀；后端与界面改为说明市场支持范围，不再提示用户重复配置 Key。未改动已保存的凭据。
