# v0.6.12 发布验收

## 范围与来源

本版从 main 的 `463173c` 开始，在隔离分支 `codex/drawing-interaction-vnext` 完成多图绘制、选中编辑、撤销／重做、ABC 四点修复以及日期与画布几何反馈；原开发目录的未提交修改未并入本版。此前 main 的开发依赖安全修复随本版发布。

版本清单、工具目录、两类归档与公开 Codex 插件快照统一到 0.6.12。中英文 README 保留全部现有图片入口，修正此前“拖动和撤销未支持”的旧说明。

## 实际 DSH 验收（2026-11-18）

DSH Web 0.2.1-rc.5，隔离 profile，DeepSeek-V4.1-Flash（High），使用真实公开日线。通过实际自然语言对话与图表交互，并核对当前对象和已确认应用记录；没有以预写工具调用代替模型执行。

| 场景 | 已确认结果 |
| --- | --- |
| QQQ 一次请求 ABC 和下降通道 | 单次多图任务；通道显示，ABC 无合格候选，不强行生成 |
| QQQ 斐波那契与下降通道 | 两个新对象作为一个原子批次；整组撤销／重做保留原 ID 和先前对象 |
| 选中通道拖动、输入及自然语言修改 | 只变指定平行点价格，其他锚点、样式、行情不变 |
| SLV 自动 ABC 正向案例 | 单次生成 0/A/B/C：10-09 55.25、10-14 50.01、10-20 52.89、10-26 47.86（纽约交易日） |
| SLV 仅修改 C 点，再撤销 | 同一 ID 的 47.86 → 48.00 → 47.86；其余字段和行情逐项相同 |
| 日期及 DST | 接口直接提供纽约本地日期；10 月为 -04:00，11-17 为 -05:00，无需模型手动减一天 |
| 平移与几何状态 | 完整在内 → 部分裁剪 → 画布外；完全移出后时间重叠为 false；重新定位恢复完整在内 |
| 时间重叠不等于价格可见 | 价格 100 水平线时间重叠为 true、几何在画布外；撤销测试线后仅保留原 ABC |

逐步过程、发现后修复的问题及测试边界见[交互验收记录](drawing-interaction-acceptance-2026-11-18.md)。

## 自动化与发行检查

本地绘图候选完成 418 项 Node/前端测试、669 项 Python 测试，另有 1 项跳过及 361 个子测试通过；覆盖原子失败、幂等重试、单点修改、对象身份、行情隔离、历史恢复、确认回执、时区与几何裁剪。发行版本再次执行构建、完整测试、目录校验及干净安装检查。

发布按现有流水线执行：候选跨平台 CI（Linux / macOS / Windows × Python 3.11 / 3.12 / 3.13）通过后进入 main，再由标签流水线构建两类归档。下载草稿资产，复核版本、SHA-256 和内容后公开 Release；npm 上传同一 TGZ，并验证 registry 与按包名安装。

首轮跨平台 CI 发现 Codex 多图工具的多行说明受 Python 版本影响，导致 3.11／3.12 的静态目录校验失败；已消除说明缩进差异，并用本地 3.11 与 3.13 复核。以修复提交的重新运行结果作为发行门槛。

远端检查结果见[跨平台 CI](https://github.com/FTShare-Lab/dsh_kline/actions/workflows/install.yml)和[发行流水线](https://github.com/FTShare-Lab/dsh_kline/actions/workflows/release.yml)。本记录不以本地通过代替远端结果。

## 未覆盖与限制

- Codex 完成运行时、共享规则和独立安装包检查；本轮未进行 Codex App 图形界面实测。
- 本地 DSH 已人工核对画面；机器反馈的几何投影不自动验证标签、遮挡或实际像素，也不覆盖全部计算形态与序列。
- 历史限当前页会话 40 项，刷新后不继承；行情来源或复权变化后不恢复旧历史。
- 形态识别条件不变，不代表所有标的和历史区间的每个候选均经人工复核。
