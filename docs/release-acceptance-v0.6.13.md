# v0.6.13 发布验收

## 范围

本轮为官网连接入口、市场页来源合并及渠道统计。绘图计算规则和鉴权方式保持不变；不把本轮测试作为全部历史形态重新人工验收。

## 本地 DSH Web

使用 DSH 0.2.1-rc.5、端口 61071，加载本地插件代码。官网入口打开 FtShare 官网，注册／登录直达官方登录表单；未提交账号或验证码，不声称完成登录后的回跳。340、500 像素宽度与中英文入口完成布局检查。

市场页加载实际指数、板块与龙虎榜数据，底部仅一处 FTShare 来源链接，携带 `utm_source=dsh_kline` 和 `utm_content=market_footer`。单元回归另覆盖不同供应商混合、缓存标签与仅板块有来源的情况。

## UTM 独立入口

独立网站版本 4，来源提交 `8c8402a00061df0b2b29afb66e0d4f5e85372070`。本地单元与数据库回滚测试通过，HTTP 集成覆盖 8 个相同编号并发请求及串行重试只计一次、第二次点击另计、HEAD／预取／无效与过期编号不增加点击；三产品分开统计，历史 `kline` 兼容。

线上验收使用 `qa-v0613-1795077281868` 活动：实际打开推广页记录 1 次访问，点击 npm 后到达正确包页且数据库只增加 1 次 npm 点击；来源为 `github / readme`、产品为 `dsh_kline`。测试活动不混入默认真实报表。仅验证跳转、渠道计数和后台访问控制；FtShare 官方内部注册／付费归因不在本轮可观察范围。

发行前执行完整 Node／Python 测试、目录与构建检查、DSH／Codex 干净安装及 GitHub 跨平台 CI；由标签流水线构建草稿附件，下载并复核 SHA-256 和版本后公开。具体结果以候选提交对应的 Actions 记录与本记录更新为准。
