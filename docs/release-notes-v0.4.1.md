# v0.4.1 · 当前图绘图交互维护版（候选）

本次只改进现有绘图工具的使用路径和结果反馈，不增加复杂绘图功能。尚未公开发布。

## 更新内容

- 当前图的创建、修改、删除统一推荐使用“读取当前图 → 准备修改 → 应用 → 确认状态”；旧快照接口保留兼容，明确不作为当前图编辑入口。
- 当前图返回支持的颜色与交互限制，目标或改价幅度不清时交由宿主澄清，不由插件猜测。
- 操作返回目标修改前后值、变化字段及是否影响其他AI图形；区分已准备、等待确认、成功确认与结果未知，不将排队误报为完成。
- 修正下载包校验文件的相对路径。

## 验证与限制

- 指定本地网页版场景中，普通中文创建两条水平线、修改指定线价、只删除指定线，均自然走通当前图链路，K线、指标和非目标对象保持一致。
- 四类图形的接口兼容与反馈摘要由自动检查覆盖；本轮没有重新进行所有图形、周期和模型组合的网页验收。
- 首次挂载偶有旧引用失效，需使用新引用；宿主回复仍可能啰嗦或附加不必要分析。
- 结果回执确认的是对象与视图状态，不是屏幕像素或专业分析准确性。图形选中、完整视图恢复、撤销、波浪、斐波那契与缠论均未新增。
- 保持“宿主理解与推理，插件观察、测量、执行和反馈”的分工。

详细候选验收范围见[维护版验收说明](release-acceptance-v0.4.1.md)。对外发布前仍须完成最终版本提交对应的远端安装与发布检查。
