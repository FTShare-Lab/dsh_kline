# v0.6.2 · 修复 Codex 启动工具目录

- 首次工具查询即返回完整、固定的桌面或 CLI 工具目录，移除对 `tools/list_changed` 的依赖。
- 桌面开图工具在首次发现时明确关联原生 MCP App 资源；CLI 不携带图表元数据。
- Python 准备期间也可预加载图表资源；资源与原有 Python 渲染内容保持一致。
- 统一 Windows 与 Unix 换行处理，确保预加载资源与 Python 资源一致。
- 普通调用有限等待，仍未就绪时明确退回；超时或取消的请求不会在稍后自动执行。
- 工具目录从实际后端生成，并检查参数 schema、App-only 可见性和资源一致性。

从 v0.6.1 升级后重启一次 Codex，然后直接请求“打开招商银行日 K”。无 Key 可用范围仍取决于免费备用源，不保证分钟或所有市场。

发布资产为 `dsh-kline-v0.6.2.tgz`、`ft-kline-v0.6.2.zip` 及同名 SHA-256。DSH 安装方式不变；Codex 仍通过本地/私有插件来源分发。

本机验收：macOS 实际重启 Codex 后，无需刷新目录即可通过插件打开招商银行日 K；原生卡片中已观察到蜡烛、均线、成交量和 MACD。此次验证为 BaoStock 不复权日线 120 根，最新日期 2026-11-03。完整记录见 `docs/release-acceptance-v0.6.2.md`；其他市场和工作台入口仍需各自验收。
