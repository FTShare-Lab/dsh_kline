# 图表高度自适应验收

日期：2026-09-07。

## 修复

- 工作台跟随实际宿主容器高度，移除 1120px 上限和 500px 外层最小高度；行情条固定占据工作台底部空间。
- 默认主图使用扣除工具栏、指标副图、操作条及结果区域后的剩余高度；高窗口不再留出大片空白。
- 容器、滚动区和内容尺寸变化都会触发重新布局；小窗口或副图过多时保留主图最小可读高度，内部滚动，不截断底栏。
- 正确区分自动高度的 null 与手动数值，避免刷新时 null 被转为 0 后锁定最小高度。
- 保留拖动及键盘手动调整；“恢复自适应”位于“设置 → 图表显示”，不再占据图表底部。底部仅保留 14px 的轻量拖动条，双击或按 Escape 也能恢复自动模式。手动和自动设置仍按当前工作台保存。

## 实测

使用隔离浏览器、真实 Harness 页面和上证指数图表：

| 浏览器高度 | 侧栏内部高度 | 图表区域高度（默认 VOL、MACD） | 结果 |
| --- | --- | --- | --- |
| 900px | 845px | 584px | 主图保持可读，内部滚动，底栏贴底 |
| 1500px | 1445px | 1065px | 初版操作条下填满可用区域，无多余纵向滚动 |
| 1800px | 1745px | 1365px | 初版操作条下随窗口继续增长，不受旧上限约束 |

- 手动增加高度后刷新保持；改变窗口不会悄悄重置手动设置。
- 点击恢复自适应，刷新仍保持自动模式，1500px 窗口图表恢复 1065px。
- 增加 KDJ、RSI、ATR 后仍按空间布局；700×650 窄短窗口保留内部滚动，底部高度按钮可访问。
- 浏览器回归未捕获未处理页面异常。
- 80 项自动化测试通过（64 Python + 16 Node），包括新增的 4 项高度计算/设置恢复测试；前端构建和资源校验通过。

## 入口视觉优化

根据用户反馈，将图表底部独立按钮移入“设置 → 图表显示”，保持现有设置样式。自动模式显示“自适应窗口”，恢复按钮禁用；手动调整后显示“手动调整”，恢复按钮可用。图表底部操作区从 28px 缩至 14px，释放的空间交给图表。

实测默认看图时按钮隐藏、手动调整后设置内恢复可用、点击恢复状态正确、双击拖动条也可恢复；80 项测试仍通过。

旧版本已保存的明确数值高度不会自动清除，以免误删用户真正的手动设置；若仍看到留白，可在“设置 → 图表显示”点击“恢复自适应”，或双击图表底部拖动条。
