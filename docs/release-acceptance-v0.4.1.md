## 保留限制

网页自然路由本轮只验证水平线。宿主可能附加不必要解释，专业判断仍需独立核对。
状态回执与候选差异不是屏幕像素证明；当前图路由是公开契约，不是后端删除旧接口或强制重定向。
返回对话恢复最后确认绘图检查点，不保证最后手动周期 / 范围 / 视口。
无图形选中、鼠标编辑、撤销、跨进程旧图编辑或完整未知操作自动恢复；波浪、斐波那契、缠论仍后置。

## 发布门槛

1. 本地完整构建、类型与全部回归检查通过。
2. 实际候选归档包含新增反馈模块及本说明，不包含本地评测、凭据与缓存。
3. 同一归档通过全新Python环境首启及独立临时DSH配置安装启动检查。
4. 用户确认发布范围与版本后，提交并验证对应Linux / Windows安装CI，通过后再打标签和发布，最后核对正式下载附件。
