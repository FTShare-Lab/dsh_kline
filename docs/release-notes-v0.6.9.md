# v0.6.9 · 自动绘图统一与图表交互修正

状态：发布候选，尚未发布。当前正式版为 v0.6.8。

- 绘图统一入口：普通图形、双顶／底、头肩顶／底、平台状态与九转都在「绘图」中选择。自动绘图默认显示最近的合格结果，支持切换候选和手动选点；关闭工具面板保留图形，清除入口位于面板内。
- DSH 与 Codex 共用自动分析注册表、默认参数和候选到图形的映射。自动结果通过当前图的受保护引用落图，保持来源校验、原子更新和应用回执。
- 修复九转标注方向和位置，普通数字按方向配色，仅突出完成的 9；消除对象更新误触发行情重算造成的重复绘图与抖动。
- 修复形态的颈线延伸、突破日期标记、锚点标签及缩放定位；平台排除明显单向漂移区间，冻结边界不随突破扩大。
- 时间栏、工具栏和绘图操作在窄画布中保持单行，多出的选项进入末尾菜单；统一主要按钮高度，缩小绘图面板，修复搜索框、设置面板和侧栏边线的遮挡。
- 指标参数设置与应用并列；点位手动添加与重新分析并列。移除冗余常驻说明，修复形态／九转模式的清除确认区不可见。
- 多标的对比可叠加在 K 线主图，提供搜索和常用指数快捷项；分图控件支持提示、折叠与恢复。
- 修复刷新页面后旧活动视图短暂残留导致的误报；保留真正多活动视图时的来源保护。
- 准备公开 npm 包 `@ftshare-lab/dsh-kline@0.6.9`；正式发布及市场目录关联完成后才能展示 npm 下载统计。下载量不等于独立安装人数。

形态与九转的识别范围、规则和限制见[规则说明](price-pattern-rules-v1.md)；当前验证结果与待完成事项见[发布验收记录](release-acceptance-v0.6.9.md)。
