# 双界面 RC 验收记录

版本：`0.2.0-rc.1`；基线：`v0.1.8`；Harness：`0.1.2-rc.1`；Better Sidebar：`0.18.0`。

## 实现范围

- 自动、经典、Better Sidebar Tab 三种偏好；仅挂载一套 K 线外壳。
- Better Sidebar 使用独立的可选依赖作用域，不在父插件的 `inject` 中强制声明；缺失时经典外壳仍能启动。
- 两套外壳共用图表组件、会话事件解析、原有存储键、行情接口和鉴权模型。
- 新增右上角界面选择器、独立自动打开偏好、首次使用欢迎和一次性升级说明、中英文及键盘支持。
- 仅使用框架公开的注册、定向打开、关闭、状态订阅接口；不访问内部 store 或模拟点击强制展开面板。
- 切回经典时清理本插件的旧 Tab 外壳（含底部和浮窗），不删除图表、标注、自选数据或其他插件 Tab。

## 真实浏览器验证

使用隔离 DSH_HOME 的两个临时 profile，无模型 Key；不需要发送付费模型请求。临时行情服务与用户现有服务使用不同端口。

| 场景 | 实测结果 |
| --- | --- |
| 未安装框架、默认自动 | 经典 K 按钮和工作台可用；上证指数行情正常；常规欢迎说明正确 |
| 未安装框架、保存 Tab 偏好 | 仍回退经典；选择器解释缺失原因；保留偏好 |
| 已安装框架、默认自动 | `+` 菜单仅注册一个 K 线项；无经典 rail / fixed panel / root 宽度残留 |
| Tab → 经典 → Tab | 保存刷新生效；自选星标、行情和已生成关键点位保留；无不可用旧 Tab 残留 |
| 首次欢迎关闭后重开 | 不重复弹出；界面选择入口仍存在 |
| 右栏、浮窗、停靠返回 | 能显示行情和标注；窄浮窗保留顶部三个操作入口 |
| 底部短面板及拖动增高 | 能打开图表；小高度保留滚动；增高后重新计算图表尺寸 |
| 切至其他 Tab 再返回 | 隐藏时图表 DOM 卸载，返回后恢复行情、偏好和标注 |
| 中英文切换 | 选择器选项、说明、保存/取消及当前模式正确切换 |
| Escape | 关闭选择器并将焦点还给“界面”按钮 |
| 约 390 CSS px 窄屏 | 三个顶部入口可操作；弹窗范围在容器内（左边约 12px、右边约 363px，容器右边 390px） |
| 浏览器错误日志 | 本轮检查未出现 console error |

测试中发现并修复：隐藏回退提示被 CSS 显示、窄容器仍按页面宽度排版、切回经典残留不可用 Tab、窄屏弹窗左侧越界。

## RC 验证边界与正式发布门槛

这不是“所有环境零问题”的承诺。以下仍需 RC 阶段在真实业务使用中补验，不能把单元测试等同于已完成全部 GUI 验收：

- 两个真实 AI 对话同时产出行情/外部 rows，Tab 自动创建、后台结果归属与旧图恢复的完整端到端链路；当前由原有事件归属/排序测试覆盖，未发起付费模型分析。
- 框架各分栏拖放组合和浮窗连续拖动/缩放的长时间使用；本轮已验右栏、底部和浮窗基本行为，未穷举所有组合。
- 从真实旧版本浏览器数据升级的首次弹窗全流程；当前已验证判定/一次性写入逻辑与首次欢迎 GUI，不把真实旧环境迁移标为已跑。
- 不同版本 Better Sidebar 的兼容性；本轮仅实测 0.18.0。

因此先发布预发布 RC，不把 `0.2.0` 标为稳定版，不更新稳定市场入口。稳定 `v0.1.8` 和 main 保留；用户可通过图表“界面”选择经典，或回退稳定 tag。FTShare Key 不需要重新配置。
