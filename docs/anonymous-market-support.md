# 无 Key 搜索与跨市场行情

证券目录、K 线、板块排行是三种独立能力。搜到代码不保证数据接口允许取数；没有 Key 也不表示所有美股数据都不可用。

## v0.6.6 起的搜索路径

- 搜索只读取本地目录和内置常用条目，不在每次输入时请求行情供应商。
- 港股后台目录来自港交所公开证券列表；美股来自 Nasdaq 的 `nasdaqlisted.txt` 和 `otherlisted.txt`，不依赖 FTShare SDK 或 Key。目录只覆盖支持表示的交易所证券，不代表 OTC 全市场或行情权限。
- FTShare 仍提供 A 股、指数与 ETF 目录；美股公开目录不可用时可尝试已有 FTShare 目录接口。网络失败保留原缓存和常用条目。
- 常用目录包含中文别名，后台刷新合并英文名称时会保留这些别名；只缓存了 A 股的旧目录不会再阻止港美股刷新至第二天。目录格式保持兼容，不清除已有缓存。

公开目录说明：[Nasdaq 字段定义](https://www.nasdaqtrader.com/trader.aspx?id=symboldirdefs)、[港交所证券列表](https://www.hkex.com.hk/eng/services/trading/securities/securitieslists/ListOfSecurities.xlsx)。目录不包含行情价格。

## v0.6.7 港美股免费日 K

无 Key 时先尝试腾讯公开日 K；配置 Key 时 FTShare 优先，仅在失败后尝试腾讯。港股支持不复权、前复权和后复权，美股支持不复权和前复权；不支持的复权不会改名冒充。按页回溯最多 4,000 根，实际数量、起止日期和不足原因会返回。成交量为历史当日股数，不随拆股复权缩放。分钟、周月线、新闻和板块排行未增加免费路径。详细合同、事件核验及边界见[免费港美股日 K](free-foreign-daily.md)。

## 行情与错误

- 港股历史 K 线使用 `hk_candlesticks`，美股使用 `eastmoney_us_stock_daily_ohlc`；失败不会改走 A 股 `stock-candlesticks`，原始的权限、限流和上游故障分类会被保留。
- 匿名接口拒绝不再显示“Key 有效”；HTTP 400 表示需要检查市场、代码或参数，不能据此认定需要升级套餐。
- 美股股类会保留，例如 `BRK.B.US` 向专用接口传 `BRK.B`。
- 无 Key 时板块排行仍未接入免费源，页面会明确说明匿名模式的范围；指数、已支持的 K 线与搜索可继续使用。配置 Key 也不自动保证所有接口有权限。

## 2026-11-05 实测与免费源评估

隔离的无 Key 环境中：FTShare 的 `AAPL.US` 日 K 请求成功，港股 `00700.HK` 专用接口返回 403 `route_not_allowed`。旧实现随后把港股请求送入 A 股接口，返回 400 并覆盖了原始原因；本次修复停止这种跨市场回退。

不使用 FTShare SDK 的公开目录实测得到 3,270 个港股目录项及 12,864 个美国交易所目录项，能够搜索特斯拉、Adobe、港交所等。数量反映本次快照，会随上市和目录过滤规则变化；英文全目录不等于全市场中文别名覆盖。

腾讯现有公开 JSON 日 K 路径也作了只读评估：请求 10 根时，`hk00700` 返回 10 根可解析日 K，`usAAPL` 仅返回 2 根。这是 v0.6.6 的初步评估记录；v0.6.7 已核对专用路由、完整美股交易所代码、历史分页与拆股/分红样本，并新增自动备用链路。未经交易所限定的 `usAAPL` 两行响应不再被采用。

上述目录和错误提示改进自 v0.6.6 提供。固定版本用户需更新至 v0.6.6；已发布 v0.6.5 的安装包保持不变。
