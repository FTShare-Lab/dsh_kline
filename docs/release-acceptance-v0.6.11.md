版本清单、静态工具目录、发行脚本与 Codex 独立插件目录统一到 0.6.11；版本化候选通过跨平台 test CI 后进入 main。标签发行流水线通过后，下载 TGZ / ZIP，复核版本、SHA-256、共享文件与公开插件目录内容，再公开 Release。
