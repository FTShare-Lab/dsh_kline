## 已完成改动

### 运行时与界面稳定性

- 改进 DSH 运行时 bootstrap：当依赖实际可用、但此前启动被中断而缺少状态指纹时，会自动恢复状态并清除旧失败记录，避免 MCP 服务被永久阻断。
- 为连续失败增加短暂冷却与重试机制，并在日志中保留失败位置，降低重复启动时的干扰。
- 检测 Python 虚拟环境解释器与 `pyvenv.cfg` 元数据不一致的情况；发现不一致时会重建环境。
- 安装 Python 依赖时隔离用户级 pip 配置，避免 `user = true` 等本地设置破坏虚拟环境安装。
- 调整 Better Sidebar 可用性判断：公开的 Tab 注册和打开接口存在时即可使用，不再因可选能力列表未暴露而错误回退到经典界面。

对应提交：`568cd8e`（`fix: recover interrupted DSH runtime bootstrap`）。
