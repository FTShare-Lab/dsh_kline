# 绘图中的自动识别

「绘图」是统一入口。普通图形优先给出近期候选，价格形态从同一入口识别，九转在用户打开后自动计算并显示数字。所有自动分析只读取当前图已加载的单日线，不抓新行情；A／港／美股当日 K 线只有到达交易所本地的保守收盘时点后才参与计算。

- 水平线：最近严格高／低拐点；趋势线：最近同侧两个已确认拐点；斐波那契：最近两个交替拐点；ABC：最近三个交替拐点，仅表示三点折线，不宣称识别艾略特波浪。候选最新锚点距最后一根已收盘日线不超过 30 根，均显示可修改的锚点。没有可信候选时仍可手动选点。
- 平行通道和平台框继续使用既有候选规则，但绘图面板只用已收盘日线调用，优先给出当前候选；可手动选点。平台突破／失效的状态由价格形态规则中的平台候选给出，不从普通矩形推断。
- 双顶／双底、头肩顶／底和平台状态使用共享的 `price_pattern_candidates` 规则。进入自动识别即分析并预览最近候选；用户可切换候选。四类反转形态允许从左到右手动指定 3／5 个锚点，仍须通过同一标准规则，不能凭手点绕过结构验证。平台手动框选走普通平台框工具。
- 九转打开后使用共享的 `nine_count` 引擎自动计算并显示逐根数字。当前图的观察版本变化时重新计算；关闭显示移除临时覆盖层。保存会固定为快照，之后只有用户主动更新才替换。

自动候选立即显示预览，保存仍由用户明确触发并核对应用回执。任意标签、任意文字、交易结论和无法由已加载行情确定的形状不自动生成。自动选点只是一种可审查的几何建议，不表示交易收益或买卖信号。
