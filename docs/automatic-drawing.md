# 绘图中的自动识别

「绘图」只有一个工具选择框，所有图形、形态和九转从这里选择。普通图形优先给出近期候选；选择双顶、双底、头肩顶、头肩底或平台状态时立即识别并绘制；选择九转时立即计算并显示数字。所有自动分析只读取当前图已加载的单日线，不抓新行情；A／港／美股当日 K 线只有到达交易所本地的保守收盘时点后才参与计算。

- 水平线：最近严格高／低拐点；趋势线：最近同侧两个已确认拐点；斐波那契：最近两个交替拐点。ABC 要求起点及 A／B／C 共四个交替拐点、三段完整走势，B 回撤为 A 段的 30%–80%，C 段为 A 段的 80%–250% 且越过 A；仍只是价格几何候选，不宣称验证完整艾略特子浪。候选最新锚点距最后一根已收盘日线不超过 30 根，均显示可修改的锚点。没有可信候选时仍可手动选点。
- 平行通道和平台框继续使用既有候选规则，但绘图面板只用已收盘日线调用，优先给出当前候选；可手动选点。平台突破／失效的状态由价格形态规则中的平台候选给出，不从普通矩形推断。
- 双顶／双底、头肩顶／底和平台状态使用共享的 `price_pattern_candidates` 规则。选中对应工具即分析并绘制最近候选；用户可切换候选，图形在同一对象中更新。四类反转形态允许从左到右手动指定 3／5 个锚点，仍须通过同一标准规则，不能凭手点绕过结构验证。平台手动框选走普通平台框工具。
- 九转打开后使用共享的 `nine_count` 引擎自动计算并绘制逐根数字，默认展示最近 30 根已收盘日线以免窄栏图表过密；历史数据仍用于预热计数。当前图的行情变化时重新计算并更新同一个图表对象。

自动候选通过受保护的准备、应用和回执流程直接绘制，关闭「绘图」不会删除图形；只有「绘图」内的「清除绘图」会移除当前图的图形与标注。任意标签、任意文字、交易结论和无法由已加载行情确定的形状不自动生成。自动选点只是一种可审查的几何建议，不表示交易收益或买卖信号。

选择自动候选时，图表会将候选锚点移入画布中央并按跨度调整缩放。之后仅缩放画布会重新定位图形；行情、标的或来源变化仍须重新分析。用户手动拖动时间轴时保留其视角。
