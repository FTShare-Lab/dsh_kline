# v0.6.11 · 宿主面板接入与挂载修复

- 新增可选 `klinePanels` 宿主契约：在模拟盘侧栏等宿主声明的槽位中复用图表，并通过 `symbol` / `onIdentity` 双向联动标的选择。
- 新增可选 `klineHost` 偏好：宿主可使用自己的入口及首启流程，按需关闭插件浮动 K 与欢迎提示；未接入时保留原有默认行为。
- 修复面板关闭后重新打开、旧清理函数误删新图表的问题。同槽位的调用方独立释放挂载，最后一个调用方释放后才卸载；支持槽位服务撤回、重新提供及失败回滚。
- 重写中英文 README，列明十二类绘图能力，保留最近的 ABC、下降通道和高清大盘、主图对比、箱体突破实例；npm 月下载量与版本徽章并列，自动更新。

接入方法见[宿主面板文档](embedding.md)，测试范围见[验收记录](release-acceptance-v0.6.11.md)。本版没有更改价格形态、九转或行情计算公式。

## 安装与更新

```sh
dsh plugin --profile web add @ftshare-lab/dsh-kline@0.6.11
```

DSH 使用 `dsh-kline-v0.6.11.tgz`，Codex 使用 `ft-kline-v0.6.11.zip`。npm 发布使用与 GitHub DSH 资产相同的 TGZ；下载统计包含重复下载和更新，不代表独立安装人数。
