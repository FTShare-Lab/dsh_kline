# 免费港美股日 K：数据合同与验证

v0.6.7 使用腾讯公开行情。无 Key 时优先走此路径，无需 FTShare SDK；有 Key 时 FTShare 优先，仅失败后尝试腾讯。仅适用于 `day`、`interval_value=1`。不会补充分钟、周月线、新闻或板块排行，也不把外国证券送入 A 股接口。

## 价格与身份

| 市场 | 不复权 | 前复权 | 后复权 |
| --- | --- | --- | --- |
| 港股 | kline/kline → day | hkfqkline/get → qfqday | hkfqkline/get → hfqday |
| 美股 | kline/kline → day | usfqkline/get → qfqday | 未支持，保留主源结果并说明限制 |

固定请求域名为 `web.ifzq.gtimg.cn`，参数为 `code,day,,end,count,mode`。不复权 mode 为空，前/后复权为 qfq/hfq；必须返回对应序列，`day` 不得冒充 `qfqday` 或 `hfqday`。港股形如 `hk00700`。美股先从固定 `qt.gtimg.cn` 公开 quote 的第 3 字段读取身份，限定证券根代码完全相同且后缀为 `.OQ/.N/.AM`，例如 `usAAPL.OQ`、`usBRK.B.N`、`usSPY.AM`。不猜交易所，不截断类别股，不支持尚未验证的其他后缀。

合同来自腾讯官网页面直接引用的 [港股图表脚本](https://st.gtimg.com/quotes/hk/zxgweb-chart-9fc1788a8403.js)、[美股图表脚本](https://st.gtimg.com/quotes/us/zxgweb-chart-8e4bcd3c375c.js)。HK 脚本 SHA-256 为 `f6ab9fb6f7df9258ab74a6c148e4480adfc260a1eab0f60ff4ba2d8488988edb`，US 为 `2c4d58ef34357a60260a4a512fe98e58f9dd44270f5ac1e2abaa2399c67796b3`。菜单、路由、成交量映射均已静态核对并与实际 JSON 样本交叉检查；未执行供应商浏览器脚本。

## 历史覆盖与时间

- 每页最多 640 根，最多 8 页，请求总量封顶 4,000 根；响应上限 2 MB、单请求超时 6 秒。使用固定 HTTPS 地址和短缓存，不执行远程代码。
- 向更早 end 日期回溯，页边界重叠；重叠行 OHLCV 必须完全相同。日期须递增、身份及复权序列须准确，非有限数、错误 OHLC 范围、负成交量会使该页无效。不混合供应商和复权基础。
- 返回实际起止时间、根数、`history_complete` 和 `coverage_reason`。数量不足、源不可用、重复返回、不遵守 end、页间口径变化均明确报告，保留已验证的较新行；`history_complete` 仅表示达到请求根数，不是交易所全历史完整性的保证。
- 一些港股累计现金分配会令早期前复权价格为零/负数。当前图表不接受非正价格，此时仅保留最近连续的正价格区间并返回 `non_positive_adjusted_prices`；不把负数改成零或删掉中间日期后继续拼接。不复权/后复权可另行请求。
- 日线用交易所日期的当地 16:00 作统一时间锚点。使用 `Asia/Hong_Kong` / `America/New_York`，美国夏令时正确切换；该锚点不是每个历史交易日真实最后成交时刻，提前收市日也保持统一约定。
- 美国当天 16:00 前、香港当天 16:15 前不纳入当天未完成日线。免费源可能延迟或中断，数据仍使用现有 freshness/status 提示；不承诺实时性、OTC、所有证券或全部公司行动的完整覆盖。
