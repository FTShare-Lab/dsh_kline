# v0.6.12 · 多图绘制、选中修改与撤销

- 一句话请求多个绘图工具，或在面板勾选「多图」；每次最多 8 项，合格图形整组显示，无候选单独说明，重试不重复创建。
- 点击选中普通几何图形，拖动锚点或输入价格，也可通过自然语言只修改指定锚点；继续使用原对象，不重新生成整张图。
- 支持绘图撤销／重做与快捷键。多图操作按整组恢复，不回滚行情、指标和视口；历史只保留当前页面会话最近 40 步。
- 修复自动 ABC 遗漏起点，直接生成 0/A/B/C 四点三段；修复选点手柄横向偏移、清除成功误报，以及搜索返回已打开标的时覆盖原图形的问题。
- 接口日期统一使用交易所本地时区，覆盖美国夏令时和冬令时。DSH 新增绘图区几何状态，区分完整在内、部分裁剪、画布外；修复平移到右侧留白后误报可视时间范围。
- 一并发布已合入的 Hono 开发依赖安全修复；未升级 DSH，也未调整形态识别条件。
- 更新中英文 README，保留现有 ABC、通道、大盘、对比与平台突破截图，补充新交互及使用边界。

## 已验收与边界

DSH Web 0.2.1-rc.5 中完成真实自然语言测试：QQQ 多图、选中修改、整组撤销／重做，以及 SLV 合格四点 ABC、仅修改 C 点和撤销。日期与几何状态另做平移裁剪及超出价格画布的水平线测试。

价格形态、九转和计算序列不开放任意拖改计算结构。几何投影不等同于标签、遮挡或像素验证。Codex 通过共享运行时与安装包检查，本轮没有进行 Codex App 图形界面实测。详见[发布验收](release-acceptance-v0.6.12.md)与[逐项实测](drawing-interaction-acceptance-2026-11-18.md)。
