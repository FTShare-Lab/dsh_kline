# dsh_kline v0.2.0

本候选版完善双界面工作台、行情跨市场适配与独立安装可靠性。

## 重点更新

- Better Sidebar 的 K 线入口按对话隔离：首次进入添加一次，不展开面板、不抢占正在使用的标签；用户关闭后会保留选择。
- 统一为“非凸K线助手 / dsh_kline”品牌，并将入口调整为简洁的纯文字 `UI`。
- 修复多个 DSH 实例共用服务定位造成的 `chart_session_unavailable` 空图；图表会话继续由不可变 token 快照安全隔离。
- 修复 FTShare 美股日线只返回一根导致 NVDA 加载失败，并修正纽约交易日的日期归一化。
- 修复 FTShare 港股日期格式和长周期获取：腾讯控股已实测日、周、月、季、年线均正常。
- 美股分钟接口不支持时改为明确的能力说明，不再误报 API Key 配置无效。
- 修复发布 tarball 丢失脚本执行位时首次启动失败；新的隔离安装冒烟覆盖中文/空格路径。

## 已验证

- Python 测试、前端 Node 测试与侧栏构建均通过。
- NVDA、AAPL 日线与腾讯控股的日/周/月/季/年线均完成真实数据源验证。
- 新对话默认 K 线入口、关闭记忆、对话隔离及经典/Tab 界面切换均完成真实网页验证。
