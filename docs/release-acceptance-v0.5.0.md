- 宿主理解自然语言并选择插件函数；插件在已核对的当前图上确定性计算，按准备→应用→状态核对创建或修改对象。

## 已知限制

- 宿主选点和解释需用户核对；ABC 不自动识浪，通道／平台候选只读且专业质量未量化。
- 当前图状态回执不是像素证明。ABC 与斐波那契在密集区域可能出现标签拥挤。
- 鼠标拖拽、撤销、缠论、完整公式语言和跨服务重启的旧图直接续改不支持；分钟线依赖数据源权限。
- 自然语言入口需要宿主下发当前图 `context_ref`；无绑定的第一轮返回 `context_ref_required`，新一轮当前图绑定后才完成验收。宿主回执不承诺像素验证；工作台另有实际画布证据。远端 macOS/Linux/Windows 安装矩阵尚未对本候选运行。只有 Python 3.10 且缺 TA-Lib 原生库的环境是否可自动首启，不能由本机通过推出。
