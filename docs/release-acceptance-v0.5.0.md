## 第一版承诺

- 宿主理解自然语言并选择插件函数；插件在已核对的当前图上确定性计算，按准备→应用→状态核对创建或修改对象。
- 用户可从「绘图」手动选点、预览并确认图形；「指标」另行管理可保存 SMA/EMA/BOLL。两种入口对新对象使用同一稳定 ID；旧手绘图仍独立，须可查看和删除。点位自动参考、手动标注统一在「点位」面板。
- 通道与平台框只读候选仅回填预览。引用与当前图数据绑定，过期不可静默保存；手动改点转为手动绘图。
- 201 个 TA-Lib 函数只读可调用；SMA、EMA、受限 BBANDS 可按明确请求落图。不能将函数数量宣传为可绘图数量。
- 现有行情、指标、视口及非目标对象不应被一次绘图修改重置。

## 已知限制

- 宿主选点和解释需用户核对；ABC 不自动识浪，通道／平台候选只读且专业质量未量化。
- 当前图状态回执不是像素证明。ABC 与斐波那契在密集区域可能出现标签拥挤。
- 鼠标拖拽、撤销、缠论、完整公式语言和跨服务重启的旧图直接续改不支持；分钟线依赖数据源权限。
- 自然语言入口需要宿主下发当前图 `context_ref`；无绑定的第一轮返回 `context_ref_required`，新一轮当前图绑定后才完成验收。宿主回执不承诺像素验证；工作台另有实际画布证据。远端 macOS/Linux/Windows 安装矩阵仍以 `test` 分支 CI 为准。TA-Lib 0.8.2 未提供 Python 3.10 官方预编译包，本候选最低版本改为 Python 3.11。
