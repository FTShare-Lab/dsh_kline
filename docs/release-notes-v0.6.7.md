# v0.6.7 · 启动恢复修复与港美股免费日 K

- DSH 首次安装依赖时由 Node 立即完成 MCP 握手并提供完整工具目录，在同一连接启动 Python，安装过程不再消耗宿主重连次数。
- 为 macOS 原生依赖冷启动预留导入探测时间，避免把较慢的首次导入误判为依赖缺失并重复安装。
- 后端退出后自动重试，保留工具注册；取消、过期及结果未知的操作不会自动重放。图表定位文件写失败时保留 MCP 工具，并在目录恢复后自动注册。
- 新增真实 `/dsh-kline/healthz`，校验后端端口及实例身份；区分定位文件缺失、权限、格式、宿主错配、进程退出和网络故障。未知路径固定返回 404。
- 后端 stderr 保存到缓存目录 `logs/backend-<host_pid>.log`（有界轮转），诊断响应不暴露服务令牌；统一侧栏与启动器的自定义缓存目录解析。

- 无 Key 可使用腾讯公开港美股日 K，无需 FTShare SDK。有 Key 保持 FTShare 优先，失败后再尝试免费源；来源明确标为腾讯。
- 港股支持不复权、前复权和后复权；美股支持不复权和前复权。美股后复权不会用不复权数据冒充。保留 BRK.B 等类别股，使用实际交易所代码。
- 有界历史分页最多 4,000 根，核对重叠页口径并返回实际覆盖、不足原因；未完成日线过滤，美国夏令时正确处理。
- 成交量为历史当日股数，复权仅作用于价格。用 NVDA 拆股、Apple 与腾讯分红记录核验并补充离线回归测试。
- DSH/Codex 双包、公开 GitHub 插件源、双语 README 和设置说明同步更新。

免费源覆盖及稳定性有限，仅新增日 K。分钟、周月线、新闻和板块排行未新增免费路径；早期非正前复权价格会明确截断。口径和核验样本见[数据合同](free-foreign-daily.md)，发布验证见[验收记录](release-acceptance-v0.6.7.md)。

GitHub 源用户刷新 `ftshare`，更新插件并重开 Codex。固定版本用户下载 `ft-kline-v0.6.7.zip`；DSH 使用 `dsh-kline-v0.6.7.tgz`。两包附 SHA-256 文件。
