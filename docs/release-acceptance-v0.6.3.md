# v0.6.3 验收

## 范围

本版为公开 GitHub 插件源及安装信息的分发更新，不新增行情、指标、绘图或凭据能力。v0.6.2 的实际 Codex 重启和原生日 K 画面验收记录仍保留在对应版本文档中，不据此宣称 v0.6.3 所有桌面操作已重新人工验证。

## 安装与自动化检查

- 根插件源 `ftshare` 指向完整独立目录 `marketplace/ft-kline`；ZIP 内保留独立的 `ftshare-local` 本地源。
- 两种插件声明、根 package、桌面 / CLI 首次工具目录及构建产物使用 v0.6.3。
- 独立目录逐文件匹配 Codex ZIP 使用的同一清单；不包含 DSH 服务或宿主钩子。
- ZIP 和独立目录均复制到全新中文 / 空格路径，检查桌面与 CLI 的首次目录、预加载资源和真实分析调用。
- 使用实际 Codex CLI 从 GitHub test 源及最终 main 源执行发现、安装与刷新，核对安装文件和版本，并检查安装后的桌面 / CLI 启动。
- 完整 Node / Python 回归与两种宿主的安装烟测均纳入现有跨平台 CI。

本机结果：构建、323 个 Node 测试、488 个 Python 测试通过（1 个跳过，361 个子测试通过）；Codex ZIP 与独立目录的桌面 / CLI 启动烟测通过，DSH 包版本及构建产物一致。

## 发布门槛

1. 将候选推送 test，等待九组跨平台检查全部通过。
2. 将同一提交快进合并 main，并创建匹配版本的 v0.6.3 标签。
3. 发布流水线再次执行完整回归、双包烟测及公开源目录校验，生成草稿。
4. 下载草稿中的两个安装包与 SHA-256 文件，核对哈希、版本和源目录内容后公开发布。

CI 结果以 GitHub Actions 对应提交记录为准，正式资产哈希以本版 Release 中同名 `.sha256` 文件为准。旧版资产不覆盖。
