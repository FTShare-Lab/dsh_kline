# v0.5.0 · 绘图工作台与 TA-Lib 计算层（发布候选）

安装要求：Python 3.11 或更高版本；Python 3.10 不在本版支持范围内。

这一版把「自然语言操作当前图」和「手动选择绘图工具」连接到同一套受保护对象：先计算或选择锚点、预览，再确认落图；之后可按稳定 ID 修改颜色、价位或锚点并删除。对象应用回执与画布目视结果分别核对。

## 新增

- 图表工具栏统一为「指标｜绘图｜点位｜预警｜对比｜清除」。SMA、EMA、BOLL 的可保存对象在「指标」中管理；「绘图」提供水平线、趋势线、平行通道、平台框、斐波那契及用户指定的 ABC 标注。旧版图形仍可查看、删除及随工作区导入导出，不自动转换坐标或 ID。
- 绘图支持单独重选锚点、预览失效后重新预览；平行通道和平台框提供只读候选。选择候选只填入预览，明确保存后才通过受控流程落图；换图或行情变化后须重新计算。
- TA-Lib 0.8.2：201 个函数可在当前已加载 K 线上搜索和只读计算；只有 SMA、EMA、受限 BBANDS 的结果在明确请求后可作为独立图形落图。图表常用指标与分析摘要统一到该计算口径。
- 条件序列线、价带、柱线、条件标注，以及只读的拐点、回归通道、通道／平台候选函数。候选结果不自动画线。

## 稳定性

- 绘图沿用当前图来源、观察版本、行情指纹、结果引用和对象 ID 保护；换标的、周期、复权或行情后不套用旧结果。序列对象在核对通过时可跨 30D 视口保留，准备回执不传逐根数组。
- 本地网页版直接搜索开图也能建立经核对的绘图来源；提案取消、确认和删除不会留下虚线草稿。

## 明确边界

ABC 是标注，不是自动识浪；通道与平台候选不是已验证的专业形态识别。「点位」自动结果是参考候选，邻近 K 线数量不等于确认次数。预警只在本页打开时检查。未集成缠论、任意公式解释器、鼠标拖拽或撤销。已确认对象可在同一宿主运行期间随页面刷新恢复，但不保证服务重启后旧图可直接续改。行情与技术分析仅供研究，不构成投资建议。
