# dsh_kline 用户体验验收清单

用于每次发布前，从普通用户视角验证安装、启动、交互、数据和恢复能力。

## 环境约定

| 环境 | 用途 | 端口 | 安装来源 |
| --- | --- | --- | --- |
| 开发环境 | 本地开发与回归 | 3080 | 当前工作区 |
| 用户环境 | 模拟新用户 | 8888 | 插件市场 |

## A. 安装

- [ ] 插件市场可搜索到 `dsh_kline`
- [ ] 安装有阶段进度和失败原因
- [ ] 不依赖开发仓库、绝对路径或开发 `.venv`
- [ ] 构建脚本需要放行时提示明确
- [ ] 中文路径和空格路径可安装
- [ ] 安装完成后能显示当前版本

## B. 首次启动

- [ ] Web 服务可启动并完成认证
- [ ] 新对话默认进入市场页
- [ ] 指数先显示，其他市场数据逐步加载
- [ ] 未配置 FTShare Key 时提示可执行
- [ ] 单个接口失败不阻塞整个插件
- [ ] 3080 与 8888 的数据和插件版本互不串用

## C. 核心交互

- [ ] 代码和中文名称搜索均可用
- [ ] 点击标的可正确打开图表
- [ ] 市场、图表、板块、资讯、公司、龙虎榜切换正常
- [ ] 自选添加、删除、分组和跨对话保持正常
- [ ] 刷新、返回、新建对话不会串标的或页签状态
- [ ] 市场卡片和龙虎榜卡片可继续打开对应标的

## D. 视觉与状态

- [ ] 指数、排行、资金、龙虎榜卡片风格统一
- [ ] 上涨、下跌、无变化颜色和格式统一
- [ ] 名称、代码、数值不重叠
- [ ] 宽窗口、窄窗口均可读
- [ ] loading、empty、unsupported、unauthorized、error、stale 状态清晰
- [ ] 不展示误导性的“全市场信息缺失”提示

## E. 更新与恢复

- [ ] 关闭并重新打开后服务可恢复
- [ ] 服务异常退出后可自动拉起
- [ ] 从旧版本升级不丢失自选
- [ ] 全新安装与已有用户升级均通过
- [ ] 发布包不包含开发文件、本机路径和测试缓存

## 首轮基础审计（2026-09-10）

| 检查项 | 3080 | 8888 | 说明 |
| --- | --- | --- | --- |
| HTTP 服务可达 | 待认证（401） | 待认证（401） | 服务端口可响应，需在浏览器完成 DSH 认证 |
| 页面人工交互 | 待确认 | 待确认 | 需认证后执行 |
| 插件安装来源 | 开发环境 | 插件市场 profile | 端口职责已固定 |
| 自动恢复 | 待确认 | 待确认 | 需完成认证和重启演练 |

## 记录规则

- `通过`：按普通用户路径完成且结果稳定。
- `失败`：功能明确异常，需要修复。
- `阻塞`：环境、认证、权限或上游数据使测试无法继续。
- `待人工确认`：自动检查无法替代真实 UI 操作。

每次发布前保留测试日期、环境、版本、结果和已知限制；未完成人工验收不得标记为“用户可用”。
