# v0.4.0 基础版验收范围

本版先交付自然语言绘图的工具与交互基础，不宣称成熟的专业技术分析机器人。
宿主负责理解、分析和选点，插件负责观察、确定性测量、执行与反馈。

## 固定任务

| 任务 | 本地指定场景结果 |
|---|---|
| 指定价位水平线 | 价位、名称、颜色符合批准值 |
| 两点趋势线 | 使用指定真实K线的低点，已有图形不变 |
| 上升通道 | 三锚点几何执行通过；最初未获宿主专业推荐，不能算专业正例 |
| 下降通道 | 主方案确认后按三锚点绘制，原通道不变 |
| 平台矩形框 | 时间、价格边界与填充正确；不支持紫色，确认橙色后执行 |
| 连续修改 | 线价与框边界更新，稳定ID与非目标内容保留 |
| 指定删除 | 只移除目标趋势线，其他图形保留 |
| 网页刷新续改 | 同宿主已确认图形恢复，可继续改价 |
| 日周切换 | 独立周线框与日线框隔离，原日线OHLCV恢复 |
| 对话往返 | 同标的、不同对话的对象与来源不混用 |

上述任务包含关联步骤，不是10个独立准确率样本。价格、锚点和对象核对不等同于屏幕像素核验、
供应商行情真值或专业形态质量。宿主附加解释仍出现数值比较、未核对外推等错误；
这类问题与插件执行正确性分开评价，使用者仍需核对分析。

## 验证方式

- 本地 macOS / Node26.7：完整构建、类型检查、203项Node及324项Python回归通过，另1跳过 / 66子测试。
- 从实际安装包验证全新Python环境首启、含中文和空格路径、MCP及行情服务、未认证HTTP拒绝。
- 独立临时DSH配置安装同一包并启动；不使用开发虚拟环境或实际用户凭据来冒充首次安装。
- 远端安装工作流覆盖Linux / Python3.10及Windows / Python3.12；发布包另经Linux打包与安装检查。
  实际通过与否以[对应提交的GitHub Actions结果](https://github.com/FTShare-Lab/dsh_kline/actions)为准。
- 重跑入口：`pnpm build:sidebar`、`pnpm test`、`pnpm pack:release`，随后运行
  `node scripts/smoke-packed-install.mjs release/dsh-kline.tgz` 和
  `node scripts/smoke-dsh-profile.mjs release/dsh-kline.tgz`。

## 明确限制

- 主验收范围为四类图形与日线 / 周线；全部分钟、市场与操作组合未验收。
- 返回对话恢复最后确认的绘图检查点，不保证离开前最后手动选择的周期、范围或视口。
  这是已知恢复范围限制，不是最后手动视图恢复通过。
- 两点线和通道为有限区间；通道 / 框按周期隔离；颜色限蓝、绿、橙、红。
- 无AI鼠标拖拽、撤销、手动对象双向编辑、跨进程旧图编辑或完整异常自动恢复。
  结果未知应停止自动重做；源信息不明不能借旧图继续修改。
- 波浪、斐波那契自然语言绘图及更多周期后续迭代；缠论低优先级。

原始本地评测对话、截图与运行文件不属于公开发布包；本说明仅保留功能范围、验证方法和限制。
