# v0.4.0 · 自然语言绘图基础版

本版先打通“用自然语言在当前图上画线、改线和删线”，复杂绘图后续逐步优化。

## 本次更新

- 新增水平线、两点趋势线、三点平行通道与平台矩形框，支持名称、蓝 / 绿 / 橙 / 红颜色、中线或填充选项。
- 宿主负责理解与选点，插件提供当前图读取、测量、受保护执行及结果核对；要求先给方案时，确认后才绘图。
- 支持指定场景下的连续修改、目标删除、同宿主网页刷新续改、日周图形隔离和对话隔离。
- 修复复权参数与分钟来源粒度衔接，改进来源 / 连接状态提示及标签布局；绘图不重置行情与指标。
- 纳入PR #10的FTShare宿主设置桥接及本地校验修正，可跟随设置中的Key变化；不在工具结果暴露凭据。

## 使用示例

> 在31.2元画蓝色水平线，叫基础支撑。
>
> 把基础支撑移到30.8元，其他图形不动。
>
> 找一段下降通道，先说三个锚点和明显偏离，确认后再画。

## 已知限制

- 本版重点验证日线 / 周线。专业选点尚未评分，宿主解释仍可能出错，不能将工具执行通过当作专业分析正确。
- 返回对话恢复最后确认的绘图检查点，不保证最后手动选择的周期、范围或视口。
- 暂不支持AI鼠标拖拽、撤销、跨进程旧图编辑和完整异常自动恢复；结果未知不自动重做。
- 分钟能力受来源 / 权限限制，不保证全部组合。波浪、斐波那契自然语言绘图后续迭代，缠论后置。
- 首次安装需Python3.10+及网络准备依赖，可能需要数分钟。行情与技术分析用于研究学习，不构成投资建议。

## 安装

优先使用DeepSeek Harness插件市场更新；也可安装下方发布附件中的`dsh-kline.tgz`：

```sh
dsh plugin --profile web add /absolute/path/to/dsh-kline.tgz
```

请按实际下载位置替换路径；附件同时提供SHA-256校验文件。

详细范围与验证方法见[基础版验收说明](https://github.com/FTShare-Lab/dsh_kline/blob/v0.4.0/docs/release-acceptance-v0.4.0.md)。
